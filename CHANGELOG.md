# Aethercraft Launcher - Changelog

## [1.0.0-alpha] - 2026-10-31
### Added
- Core System Inspector for hardware, Android OS, kernel, CPU, RAM, storage, and Java detection.
- JVMOptimizer with dynamic memory capping and Android OOM safety margins.
- Instance Manager and real Launch Pipeline for Minecraft Java instances.
- FSR Manager and dynamic resolution scaling algorithms.
- Frame Generation subsystem interface (`FrameGenerationBackend`).
- Gemini AI crash analyzer (`GeminiProvider`) for log diagnostics without hardcoded keys.
- Benchmark runner for FPS, frame time, and 1% low metrics.
- Comprehensive automated test suite (`tests/test_aethercraft.py`).
- Detailed documentation (`ARCHITECTURE.md`, `DEVELOPMENT_STATE.md`, `REQUIREMENTS_MATRIX.md`).
